# 0.2.2 phone UI repair — September 29, 2026

The user's screenshots showed duplicate horizontal tool navigation, clipping,
low contrast, overlapping native tab labels and a blank terrain map. Browser
reproduction at a 393px viewport showed a 1195px document width and an uncaught
JavaScript syntax error. The Android shim had been inserted inside two report
HTML strings, terminating the script and spilling report markup/styles into the
page. An earlier Android-only toolbar also duplicated the website toolbar.

## Changes

- One searchable tool chooser; 13 existing tool panels remain reachable.
- Charcoal/teal theme, legible labels, 44–48px controls, responsive forms,
  phone-sized result cards and a terrain map above the configuration inputs.
- Separate page, calculator script, navigation script and styles. The UI no
  longer depends on a global HTML substitution or remote font/icon scripts.
- Bundled, pinned Leaflet 1.9.4, GeoTIFF 2.1.3 and Phosphor 2.1.2 assets with
  licenses and checksums. Local content uses AndroidX WebViewAssetLoader's
  HTTPS origin; arbitrary file access and mixed content are disabled.
- Real map initialization, in-scope mesh initialization, accurate selected map
  layer, and a tile-unavailable explanation/retry action. A map grid is not
  substituted terrain imagery. Imagery and online elevation still need network.
- The absent service-worker cache controls were removed. The previously absent
  MafiaLRS target database now reports its unavailability instead of throwing.
  This change does not invent or download a firmware catalog.
- Native content and bottom tabs occupy separate layout regions. System and
  keyboard insets are consumed once. Android Back closes the tool chooser first.
- Android file selection for imported elevation files.
- Visual review exposed pre-existing range formula errors: input mW incorrectly
  received the watts-to-dBm offset, and the path-loss constant used the wrong
  distance units. Fixed both and labelled the result as a free-space limit.

## Software verification

- 22 Android tests: 17 telemetry + 5 startup/navigation/resource tests.
- A real Android Material bottom-navigation render was inspected. A geometry
  assertion verifies that labels do not overlap icons or the content area.
- The pinned Playwright 1.56.1 suite passes 39 chooser/navigation checks across
  all 13 panels at 360px, 393px and 800px widths. No form controls are clipped.
- Search, FC matching, range calculation, offline map startup, two-point map
  placement and mesh navigation pass with all external network requests blocked.
- Numerical regression checks verify 1000 mW = 30 dBm and the MHz/km path-loss
  calculation. No uncaught JavaScript errors were observed.
- Separate visual review loaded six actual USGS map tiles successfully. This
  confirms rendered imagery in the software preview, not phone connectivity.
- `testDebugUnitTest assembleDebug lintDebug` passes; lint has 0 errors and 81
  warnings. No warnings were suppressed. The APK signature matches 0.2.1.

Run the UI suite:

```sh
cd tools/ui-tests
npm ci
npx playwright install chromium
npm test
```

The CI workflow runs both suites and retains UI screenshots/test artifacts.
The Android tests cover the native layout; Playwright executes the same bundled
HTML/JS at the same asset origin. No physical Android/controller session was available
in this environment. Controller telemetry acceptance remains in
[USB_CONTROLLER_SETUP.md](USB_CONTROLLER_SETUP.md).
